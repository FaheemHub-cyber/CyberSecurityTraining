Quick Reference Hub

Password & MFA Golden Rules

  • Always use approved password manager.
  • Never reuse passwords across personal/work accounts.
  • MFA is mandatory on every internal & cloud service.
  • Never approve unrequested MFA push notifications.

Data Classification

  • Public: Open marketing materials.
  • Internal: Company wiki, team docs.
  • Confidential: Financials, customer contracts.
  • Restricted: PII, API keys, source code.

Phishing Red Flags

  • Artificial urgency or fear tactics.
  • Sender email domain typo-squatting.
  • Mismatched links (hover before click).
  • Requests for gift cards, wire transfers, or credentials.
